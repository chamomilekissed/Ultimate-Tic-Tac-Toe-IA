# Versión anterior

Esta carpeta conserva el archivo `gato_de_gatos_anterior.py` para mostrar cómo
evolucionó el proyecto.

No es la versión final ni el archivo recomendado para entregar. El código
actual para Spyder está en:

```text
codigo_final_spyder/gato_de_gatos.py
```

## Por qué se conserva

- Permite comparar decisiones de diseño.
- Sirve como evidencia del trabajo previo.
- Ayuda a explicar por qué se añadieron módulos, clases y más pruebas.

La versión anterior usa listas y funciones dentro de un solo archivo. La
versión actual ofrece una clase `Tablero`, una estructura modular para estudiar
el código y un archivo único equivalente para Spyder.

La comparación completa está en
[`../documentacion/cambios_version_anterior_a_actual.md`](../documentacion/cambios_version_anterior_a_actual.md).
